# SF Seasonal Produce Guide

A web app that shows which fruits and vegetables are at peak freshness in the
San Francisco Bay Area, month by month.

- Pick any month (defaults to the current one) to see what's **at peak**,
  what's **also in season**, and what's **out of season**
- Fruit / vegetable filters, produce search, and a one-month look-ahead
- Expandable tips on selection, storage, and serving for each item

## Data

Seasonality data is compiled from public Bay Area / California sources:

- [Foodwise seasonality charts](https://foodwise.org/eat-seasonally/seasonality-charts/)
  (formerly CUESA; Ferry Plaza Farmers Market, San Francisco)
- [California Grown "Eat the Season" chart](https://californiagrown.org)
  (familykitchenvc.info PDF)

Seasonality is approximate — every year is different, and individual
varieties have different harvest times. When in doubt, ask your farmers
market vendor.

## Source

`index.html` is a self-contained export of the app (HTML + CSS + JS, no
build step). Open it in any browser.
